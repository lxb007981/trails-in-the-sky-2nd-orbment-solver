# 空之轨迹 the 2nd 导力器求解器

原生 HTML / CSS / JavaScript 页面，无需安装依赖。使用仓库已有的角色 JSON 和制表符分隔回路文件，在浏览器本地按 `SOLVER_RULES.md` 搜索合法最小配置。

## 本地启动

需要 Node.js 22 或更新版本。

```sh
npm run dev
```

访问 http://127.0.0.1:5173 。页面通过 fetch 读取数据，因此请通过 HTTP 启动，不要直接双击 HTML。静态部署时保留 index.html、src/ 和两个数据文件的相对路径即可。字体使用本机字体，无需访问外部字体服务。

## 已实现

- 角色选择、按角色数据绘制链条、中央孔与属性限定提示。
- 地、水、火、风、时、空、幻七种非负整数属性需求。
- 可搜索的回路多选下拉框、必选与排除互斥、标签移除、条件重置。
- 待配置、求解中、无解、结果、搜索截断及错误状态。
- 孔位限定、刃盾理分类限制、功能系列全局互斥、必选与排除校验。
- 不可再删和向下替换检查、同链位置及逐回路等属性去重；第 21 个不同策略出现时停止并返回前 20 个。
- 窄屏布局、键盘操作、表单校验。条件改变时取消旧请求，避免旧结果覆盖新条件。
- 最多缓存 500 组求解结果（含无解），相同条件优先读取缓存；选择顺序不影响命中。使用浏览器本地存储，刷新后仍有效，超限时淘汰最久未使用的记录。存储不可用或空间不足时退回本页内存缓存。
- 醒目的「清除缓存」按钮保留当前输入，取消正在进行的计算并清空结果缓存；结果异常或报错时可清除后重新计算。角色、回路或魔法数据变化时旧缓存自动失效；修改求解规则或返回格式时需递增 `src/solver-cache.js` 中的 `CACHE_VERSION`。

## 求解接口

`src/solver.js` 提供异步 `solveOrbment(request, context)`。功能系列的明确名称映射位于 `src/quartz-families.js`；未列入升级系列的回路各自独立成系，同名仍不能重复装备。

请求示例：

```js
{
  characterId: 'estelle',
  minimumAttributes: { 地: 0, 水: 3, 火: 0, 风: 0, 时: 0, 空: 0, 幻: 0 },
  artRequirements: [{ 时: 9 }, { 水: 3, 风: 3, 空: 3, 幻: 6 }],
  requiredQuartzIds: ['防御1'],
  excludedQuartzIds: ['防御2']
}
```

`minimumAttributes` 和可选的 `artRequirements` 数组中每一项都是独立目标，每组需由同一条链满足，各组可以使用不同链。选择魔法会按各属性最大需求更新界面数值，取消选择时重新计算，并保留手动要求。自动汇总只用于显示；提交时 `minimumAttributes` 仅包含手动设置的属性，魔法需求通过 `artRequirements` 独立传递。回路 ID 使用数据中唯一的名称。`context.characters` 为原始角色数据；`context.quartz` 包含 `{ id, name, element, attributes }`，数组顺序决定等属性方案的展示优先级；`context.signal` 用于取消请求。搜索定期让出主线程，取消时抛出 `AbortError`。

响应约定：

```js
// 无解
{ status: 'no-solution', solutions: [], message: '可选说明' }
// 有解（以下仅表示数据结构；空孔省略，返回所有链及完整七项属性）
{
  status: 'solved',
  truncated: false,
  message: '完整搜索，共 1 个策略。',
  solutions: [{
    id: 'solution-1',
    slots: [{ slotId: 'center', quartzId: '防御1' }],
    lines: [{ slotIds: ['center', '1-1', '1-2', '1-3'], attributes: { 地: 1, 水: 3 } }]
  }]
}
```

超过 20 个策略时返回 `truncated: true` 和消息「超过 20 个，已停止搜索」。恰好 20 个时继续检查剩余搜索空间，只有完整搜索后才能返回 `truncated: false`。无解时不降低目标。非法请求（例如未知角色、非法属性值）抛出异常，由界面显示错误。

算法先分配必选回路，再逐个补齐尚未满足的目标，按候选达标链搜索可选回路组合。链成员关系相同的孔合并搜索，展示时通过孔位匹配还原合法排列。候选结果逐项检查删减与向下替换，等属性名称则联合检查互斥及孔位规则后优先选取表格靠前的合法最小方案。困难条件仍可能需要较长搜索时间，可修改条件取消。

执行 `npm test` 可检查真实数据解析、规则边界、搜索截断、取消行为及小规模穷举对照。
